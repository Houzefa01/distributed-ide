🚀 DÉMARRAGE RAPIDE
────────────────────────────────────────────────────────────────────────────────

Option 1: Compiler directement
   $ cd /home/hsavatra/distributed-ide
   $ pdflatex PRESENTATION_DISTRIBUTED_IDE.tex
   
Option 2: Utiliser le Makefile (recommandé)
   $ make          # Compile et genère PDF
   $ make clean    # Nettoie les fichiers temporaires
   $ make view     # Ouvre le PDF
   $ make rebuild  # Clean + compile

Option 3: Compiler pour présentation (fullscreen)
   $ pdflatex -interaction=nonstopmode PRESENTATION_DISTRIBUTED_IDE.tex
   $ evince PRESENTATION_DISTRIBUTED_IDE.pdf   # Visionneuse PDF

AVANT LA PRÉSENTATION:

1. Testez l'affichage
   - Projecteur/écran compatible
   - Résolution 16:9 minimum
   - Luminosité OK
   - Son testé

2. Préparez le matériel
   - PDF ouvert et prêt
   - Terminal accessible
   - Code source visible
   - Demos lancées en avance

3. Timing
   - 30 minutes total = strict
   - 4 min + 6 min + 8 min + 4 min + 4 min + 2 min + 2 min
   - Pratiques multiples
   - Chronométrez avec Beamer timer


PENDANT LA PRÉSENTATION:

Raccourcis Beamer:
   B      → Mode blackout (écran noir)
   W      → Mode whiteboard (écran blanc)
   S      → Slide sorter (miniatures)
   N      → Slide counter (time left)
   G      → Goto slide (numéro)
   . ou Q → Quitter

Navigation:
   Espace / →  Slide suivante
   Retour / ← Slide précédente
   Ctrl+X →  Couper audio
   
Fullscreen:
   F5 / F11 → Mode présentation desktop
   Dans PDF viewer: button fullscreen

🔧 CUSTOMISATION
────────────────────────────────────────────────────────────────────────────────

Pour modifier les couleurs:
   Ouvrez PRESENTATION_DISTRIBUTED_IDE.tex ligne ~30:
   
   \definecolor{DistribIDEBlue}{RGB}{25, 118, 210}
   \definecolor{AccentOrange}{RGB}{255, 152, 0}
   
   Changez les valeurs RGB selon vos préférences.

Pour ajouter des slides:
   Copiez le template:
   
   \begin{frame}
     \frametitle{Titre}
     [Contenu]
   \end{frame}

Pour ajouter des images:
   1. Téléchargez l'image (PNG/JPG) dans le même dossier
   2. Ajoutez:
      \includegraphics[width=5cm]{nom_image.png}

Pour modifier les diagrammes TikZ:
   Chaque \begin{tikzpicture}...\end{tikzpicture} peut être personnalisé
   Voir documentation TikZ pour advanced features

🐛 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────────

ERREUR: "pdflatex: command not found"
SOLUTION: 
   $ sudo apt update && sudo apt install texlive-full
   # (ou xcode-select --install sur macOS)

ERREUR: "! File not found"
SOLUTION:
   Assurez-vous que PRESENTATION_DISTRIBUTED_IDE.tex est dans le dossier courant
   $ pwd  # Doit afficher /home/hsavatra/distributed-ide
   $ ls PRESENTATION_DISTRIBUTED_IDE.tex

ERREUR: PDF très gros (>5MB)
SOLUTION:
   Les images TikZ sont peut-être trop complexes
   Simplifiez ou convertissez en PNG d'abord

ERREUR: Slides décalées/mal alignées
SOLUTION:
   Effacez les fichiers temporaires:
   $ make clean
   Recompilez:
   $ make
