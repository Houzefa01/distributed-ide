KEYBOARD SHORTCUTS
Implementation: EditorManager.setupTabKeyboardShortcuts()

Pattern:
  tabPane.setOnKeyPressed(event -> {
      if (event.isControlDown()) {
          switch (event.getCode()) {
              case W:         closeCurrentTab(); break;
              case TAB:       selectNextOrPreviousTab(); break;
              case PAGE_DOWN: selectNextTab(); break;
              case PAGE_UP:   selectPreviousTab(); break;
          }
          event.consume();  ← Prevent propagation
      }
  });

Features:
• Circular navigation (wraps at boundaries)
• Immediate response (<50ms)
• Proper event consumption
• Logging for debugging

DIRTY FILE INDICATORS
Implementation: EditorManager.markDirty()/markClean()

Pattern:
  // When file is modified
  tab.getStyleClass().add("tab-dirty");
  
  // When file is saved
  tab.getStyleClass().remove("tab-dirty");

CSS Styling (5 themes, consistent pattern):
  .tab-dirty {
      -fx-background-color: -ide-bg-active;
      -fx-border-width: 0 0 2 0;
      -fx-border-color: -ide-warning;  ← Theme-specific color
  }
  
  .tab-dirty .tab-label {
      -fx-font-weight: bold;
      -fx-text-fill: -ide-warning;
  }

Theme Colors:
• Dark Theme:   #f1fa8c (yellow)
• Light Theme:  #cc6633 (orange)
• Dracula:      #f1fa8c (yellow)
• Nord:         #ebcb8b (golden)
• Modern:       #fbbf24 (amber)

RESOURCE MANAGEMENT
Implementation: EditorManager.closeEditor()

Cleanup Steps:
1. Remove tab from pathToTab map
2. Remove editor from pathToEditor map
3. Remove from dirtyFiles set
4. Call editor.dispose() for thread cleanup
5. Remove tab from UI pane
6. Log all operations

Benefits:
• Prevents memory leaks
• Cleans up highlighting threads
• Removes dirty file tracking
• Proper resource disposal

───────────────────────────────────────────────────────────────────────────────
ARCHITECTURE NOTES
───────────────────────────────────────────────────────────────────────────────

Key Design Decisions:
1. CSS-Based State: Use classes instead of text mutations (clean separation)
2. Circular Navigation: Wrap at edges for professional IDE feel
3. Event Consumption: Prevent propagation to nested controls
4. Resource Disposal: Explicit cleanup to prevent memory leaks
5. Modulo Arithmetic: For efficient wrapping calculations

Patterns Established:
• Keyboard event handling in setupTabKeyboardShortcuts()
• CSS class management in markDirty()/markClean()
• Resource disposal in closeEditor()
• Proper logging at all levels

Integration Points:
• CRDT: No interaction with dirty indicators (visual only)
• Save Service: Calls markClean() after successful save
• File I/O: Uses path tracking from existing system
• Theme Manager: Reads color variables from theme files
