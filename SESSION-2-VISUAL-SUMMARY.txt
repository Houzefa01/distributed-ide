┌─────────────────────────────────────────────────────────────────────────┐
│ ⚡ ARCHITECTURE DECISIONS                                               │
└─────────────────────────────────────────────────────────────────────────┘

1. CSS-Based State Management
   Rationale: Cleaner separation of concerns (UI vs logic)
   Benefit: Easier theming, better performance
   Pattern: Use CSS classes, not text mutations

2. Circular Tab Navigation
   Rationale: Professional IDE behavior (VS Code standard)
   Benefit: Intuitive user experience
   Implementation: Modulo arithmetic for wrapping

3. Event Consumption Pattern
   Rationale: Prevent event propagation
   Benefit: Avoid conflicts with nested controls
   Implementation: event.consume() after handling

4. Explicit Resource Disposal
   Rationale: Prevent memory leaks
   Benefit: Clean shutdown, lower memory footprint
   Implementation: Call dispose() before removing
